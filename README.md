# 物品角标

《深空当铺》模组：在葡萄、酵母、水、成品酒、枪械、金属锭和化学品的角落画出品质角标（色块 / 像素数字 / 箭头）。只改显示层，不修改游戏数值、配方或价格公式。兼容《酿酒拓展》。

A *Probably Stolen* display-only mod that draws a corner quality badge on berries, yeast, water, wine, guns, metal ingots, and chemicals. Compatible with Brewing Expansion.

**适配游戏：** 1.0.0（覆盖该补丁全部热修复）  
**作者：** kirkxia

## 做什么

同类物品外观接近，品质与纯度藏在标签、悬停提示或鉴定结果里。本模组在物品格子一角叠加一个小色块（支持只显示色块、像素数字或方向箭头），旋转后仍贴紧最近实际占用格，单格（1×1）物品会自动缩小角标减少遮挡：

- **葡萄 / 酿酒果实**（需**放大镜**）：对酒分的贡献。发霉 `-1`，欠熟 / 过熟 `+0`，正常 `+1`，小颗 `+2`。兼容《酿酒拓展》果实、巨大果和原浆（原浆随葡萄开关；按档位取四颗均分，按评分显示总分）
- **酵母**（不需工具）：默认酿酒值一律 `+1`，颜色区分普通 / 超级 / 可循环（紫）/ 非法（红）；也可改显示发酵天数。兼容《酿酒拓展》反应器酵母
- **水**（仅含水容器）：基础水为 `+0`。可按水品质档或酿酒水质分 W 显示。标签档不需工具；真实档需 AquaScan 或未用试纸
- **酒**（不需工具）：自酿（酒分 2）为 `+0`，琼浆（6）为 `+3`；更高分同色、数字继续加。也可改显示酒分原值。假酒为紫色 `x`。兼容《酿酒拓展》配方酒
- **枪械**（不需工具）：良好为 `+0`。差 `-2` / 一般 `-1` / 良好 `+0` / 极佳 `+1` / 新品 `+2`。成色档跟「纯度显示」。只标枪械与电击枪，冷兵器不标
- **金属锭**（不需工具）：平均（Fair）为 `+0`。极低 `-2` / 低 `-1` / 平均 `+0` / 高 `+1` / 极高 `+2` / 完美 `+3`。可看标签或真实纯度
- **化学品**：街头标准为 `+0`。淀粉 `-3` / 垃圾 `-2` / 掺假 `-1` / 街头 `+0` / 近制药 `+1` / 制药 `+2` / 实验室 `+3`。标签档不需工具；真实档需成分光谱仪

默认配色「黑红灰白黄蓝绿」七色正中（白色）为 `+0`。可换成「黑红灰白绿蓝黄」或「灰白绿蓝紫金红」（蓝色为 0，红色最高）。

## 怎么用

1. 把模组文件夹放到游戏的 `Mods\` 下，启动游戏，在「模组」菜单里**启用**，然后**重启**一次。
2. 进入存档后，符合条件的物品格子角落会自动出现角标。默认显示在右下角，默认读取**标签纯度**（不需要分析仪）。
3. 改成**真实纯度**后：水需要水质检测仪（AquaScan 或未用试纸），化学品需要成分光谱仪。葡萄与原浆无论何种模式均需要放大镜。工具放在手上、店里、工具箱格子或走私者暗格里都会被识别。
4. 不想看某类物品时，到模组齿轮设置里关掉对应开关即可；品质对照表默认收起，需要时再打开。

## 设置

游戏主菜单 → 模组 → 本模组右侧齿轮：

| 分区 | 设置 | 默认值 | 说明 |
|---|---|---|---|
| 外观 | 角标样式 | 数字 | 仅色块 / 数字 / 箭头 |
| 外观 | 配色方案 | 黑红灰白黄蓝绿 | 黑红灰白黄蓝绿 / 黑红灰白绿蓝黄 / 灰白绿蓝紫金红 |
| 外观 | 角标位置 | 右下 | 左上 / 右上 / 左下 / 右下 |
| 对照 | 显示品质对照 | 关 | 打开后画出各类色阶图例并实时预览 |
| 葡萄 | 显示葡萄品质 | 开 | 含《酿酒拓展》果实与原浆 |
| 酵母 | 显示酵母种类 | 开 | 开关 |
| 酵母 | 酵母数值 | 酿酒值 | 酿酒值 / 发酵天数 |
| 水 | 显示水纯净度 | 开 | 开关 |
| 水 | 水质数值 | 按水品质 | 按水品质 / 按酿酒值 |
| 水 | 纯度显示 | 标签纯度 | 标签纯度 / 真实纯度（水、化学品、锭、枪共读此项） |
| 酒 | 显示酒品质 | 开 | 开关 |
| 酒 | 酒品质数值 | 按档位 | 按档位（自酿 0 / 琼浆 +3）/ 按评分 |
| 武器 | 显示枪械成色 | 开 | 只标枪械与电击枪 |
| 金属锭 | 显示金属锭纯度 | 开 | 开关 |
| 化学品 | 显示化学品纯度 | 开 | 开关 |

## 安装

把整个模组文件夹放到：

`…\steamapps\common\Probably Stolen\Mods\ItemBadges\`

文件夹里至少要有 `manifest.xml`、`ItemBadges.dll`、`Localization\`。启用后必须重启游戏。

从源码编译（需要 [.NET SDK](https://dotnet.microsoft.com/download) 6.0+ 和一份正式版游戏）：

```powershell
dotnet build -c Release
```

会生成 `dist\ItemBadges\`，并自动复制到游戏的 `Mods\ItemBadges\`。游戏不在默认 Steam 路径时，复制 `GameDir.local.props.example` 为 `GameDir.local.props` 并改里面的路径。

## 卸载

在模组菜单里停用并重启即可。纯显示层模组，不写入存档数据，不影响存档和已有物品。
