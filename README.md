# 物品角标

《深空当铺》模组：在葡萄、酵母、水、成品酒、金属锭和化学品的角落画出品质角标（色块 / 像素数字 / 箭头）。

A *Probably Stolen* mod that draws a corner badge on berries, yeast, water, wine, metal ingots, and chemicals.

**适配游戏：** 1.0.0.13（商店标签 100-Rev13）  
**作者：** kirkxia

## 做什么

同类物品外观接近，品质藏在鉴定或酿造结果里。本模组在格子一角加一个小色块：

- **葡萄**（需**放大镜**）：对酒分的贡献。发霉 -1，欠熟 / 过熟 0，正常 +1，小颗 +2
- **水**：基础水为 0。可按水品质档或酿酒水质分 W 显示。标签档不需工具；真实档需 AquaScan 或未用试纸
- **酒**（不需工具）：量产（酒分 3–4）为 0。难以下咽 / 粗桶 / 手工 / 量产 / 臻品 / 琼浆；假酒为紫
- **酵母**（不需工具）：普通 +1；超级 +2；非法为紫 x；可循环为紫 ∞
- **金属锭**：平均（Fair）为 0。极低 -2 / 低 -1 / 平均 0 / 高 +1 / 极高 +2 / 完美 +3。可看标签或真实纯度
- **化学品**：街头标准为 0。淀粉 -3 / 垃圾 -2 / 掺假 -1 / 街头 0 / 近制药 +1 / 制药 +2 / 实验室 +3。标签档不需工具；真实档需成分光谱仪

默认色阶七色正中为 0：黑 −3 → 红 −2 → 深灰 −1 → **白 0** → 黄 +1 → 蓝 +2 → 绿 +3。可换成「绿蓝黄」或「灰白绿蓝紫金红」（蓝为 0，红最高）。最低档黑底白字。

## 怎么用

1. 把模组文件夹放到游戏的 `Mods\` 下，启动游戏，在「模组」菜单里**启用**，然后**重启**一次。
2. 进存档后，符合条件的物品格子角落会出现角标。默认显示**标签纯度**，不需要分析仪。改成真实纯度后：水要水质检测仪，化学品要成分光谱仪（工具箱格子、走私者暗格里也算）。葡萄仍要放大镜。默认画在右下角，物品旋转后仍贴在格子的同一角。
3. 不想看某类物品时，到模组齿轮里关掉对应开关。

## 设置

游戏主菜单 → 模组 → 本模组右侧齿轮：

| 设置 | 说明 |
|---|---|
| 角标样式 | 仅色块 / 数字 / 箭头（空心三角；可循环酵母仍为 ∞） |
| 配色方案 | 黑红灰白黄蓝绿 / 黑红灰白绿蓝黄 / 灰白绿蓝紫金红 |
| 角标位置 | 左上 / 右上 / 左下 / 右下 |
| 水质数值 | 按水品质，或按酿酒值 W（纯水与优质均为 +1） |
| 纯度显示 | 标签纯度（贴纸档，默认）/ 真实纯度（水需检测仪，化学品需成分光谱仪） |
| 品质对照 | 色阶与各类预览；档位说明在 info 提示里 |
| 显示葡萄 / 酵母 / 水 / 酒 / 金属锭 / 化学品 | 各类各自开关 |

## 安装

把整个模组文件夹放到：

`…\steamapps\common\Probably Stolen\Mods\ItemBadges\`

文件夹里至少要有 `manifest.xml`、`ItemBadges.dll`、`Localization\`。启用后必须重启游戏。

从源码编译（需要 [.NET SDK](https://dotnet.microsoft.com/download) 6.0+ 和一份正式版游戏）：

```powershell
dotnet build -c Release
```

会生成 `dist\ItemBadges\`，并自动复制到游戏的 `Mods\ItemBadges\`。游戏不在默认 Steam 路径时，复制 `GameDir.local.props.example` 为 `GameDir.local.props` 并改里面的路径。

## 卸载

在模组菜单里停用，重启即可。只改显示，不影响存档和物品。
